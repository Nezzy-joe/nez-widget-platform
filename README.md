# Nez Widget Platform

An embeddable widget and lead-capture platform built with Go.

## Project Status

Phase 1 — Design

## Overview

This platform will allow customers to create embeddable widgets and install them on external websites with a small JavaScript snippet.

Visitor submissions will be validated, protected against abuse, optionally enriched with location data, persisted, and exposed through an authenticated dashboard API.

## Planned Features

- Multi-tenant widget management
- Authenticated widget CRUD
- Embeddable JavaScript widget
- Public widget configuration endpoint
- Cross-origin lead submission
- Input validation
- Rate limiting
- Spam protection
- Geo-enrichment fallback
- Safe email/webhook side effects
- Background processing
- Dashboard and analytics
- PostgreSQL persistence

## Technology
